# Password Generator

A simple Python-based command-line password generator.

## Features
- Custom password length
- Toggle inclusion of uppercase letters, numbers, and special characters
- Built using standard Python libraries

## How to Run
Run the script using python:
```bash
python password_generator.py [length]
```
Example:
```bash
python password_generator.py 16
```

## Running Tests
Run the unit tests with:
```bash
python -m unittest test_password_generator.py
```
